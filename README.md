# Smart Student Management System

## 📌 Project Overview
The Smart Student Management System is a beginner-friendly Java console application developed to manage student academic records efficiently. The program stores multiple student details, calculates total marks, average, and grades automatically, and identifies the topper using functions.

This project demonstrates fundamental Java programming concepts such as arrays, loops, conditional statements, functions, and user input handling using the Scanner class.

---

## 🎯 Features
- Store multiple student details
- Input roll number, name, and marks
- Calculate total and average marks
- Assign grades using conditions
- Display all student details
- Find and display topper using functions
- Beginner-friendly console application

---

## 🛠 Technologies Used
- Java
- Scanner Class
- Arrays
- Functions/Methods
- Loops
- Conditional Statements

---

## 📂 Program Structure

### Functions Used
1. `calculateGrade()`
   - Calculates student grade based on average marks.

2. `displayTopper()`
   - Displays topper details separately.

3. `main()`
   - Handles user input, calculations, and overall program flow.

---

## 📊 Grade Criteria

| Average Marks | Grade |
|---------------|-------|
| 90 and above  | A |
| 75 and above  | B |
| 50 and above  | C |
| Below 50      | F |
